GridWorld Quest

Walk 🟡 from start to the flag 🏁 using the arrow keys. Every step costs a point, red tiles cost more, reaching the flag pays off big. Then unleash a Q-learning agent on the same grid and see who plans better.

🧩 Intermediate ~3 min Concept: Reinforcement Learning
Level 1 of 2
Arrow keys (or the pad below) to move. Reach the flag in as few steps as possible, avoiding red tiles.
📌 Reward rule
Every move: −1. Landing on a red tile: −5 more. Reaching the flag: +10 and the level ends. Hitting a wall wastes a move. Higher total reward is better.
